# Categories

The public category allowlist — the publication boundary between the vault and the site. A top-level folder is a category only if its name has no leading `.` or `_` **and** it is listed in the front-matter above. The site renders listed categories only; an unlisted no-prefix folder is eligible but never rendered.

To add a category: create the folder, add its name to the front-matter list, and describe it below.

- **Articles** — long-form finished writing.
- **Projects** — ongoing work with a goal and status.
- **Logs** — short-to-medium dated entries, one per day, chained newest → previous.
