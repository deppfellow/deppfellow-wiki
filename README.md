# Deppfellow LLM Wiki

A personal knowledge base and shared memory layer for me and my AI agents, built in Obsidian and synced via Git.

## Structure

- `Articles/` — long-form writing
- `Projects/` — ongoing work
- `Logs/` — chained, dated entries

Each folder is a **category**. A top-level folder counts as a category only if its name has no leading `.` or `_`; everything else is meta or tooling.
